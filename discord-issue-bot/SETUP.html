Discord Issue Bot — Token Setup Guide

Follow these 5 steps to collect the secrets you need: a Discord bot token, your guild (server) ID, a GitHub token, and a role name. Everything you need is one click away.

1

Create a Discord Application (bot token)

  • Open the Discord Developer Portal and click New Application (top-right).
  • Give it a name (e.g. Issue Butler) and click Create.
  • In the left sidebar, go to Bot → click Reset Token → Yes, do it!
  • Click Copy — this is your DISCORD_TOKEN. Save it somewhere safe (shown only once).
DISCORD_TOKEN = MTA5xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
📌 Privileged intent: the bot's !issue / !ability text commands need the Message Content privileged intent — turn it ON under Bot → Privileged Gateway Intents (Presence / Server Members can stay off).

Open Developer Portal →

2

Invite the bot to your server

  • In the same application, go to OAuth2 → URL Generator.
  • Check bot under Scopes, then under Bot Permissions check:
    • Send Messages
    • Embed Links (optional, for nice embeds)
    • Read Message History (so it sees !issue text commands)
  • Copy the generated URL at the bottom and open it in a new tab.
  • Pick your server, click Authorize (you need Manage Server permission).

Back to Developer Portal → Invite URL (replace YOUR_APP_ID)

📌 Your application ID is on the General Information page — copy it now, you'll need it for Step 3.
3

Get your Guild (server) ID

  • In Discord, open User Settings → Advanced and turn on Developer Mode.
  • Right-click your server's name (top-left) → Copy Server ID.
  • That 17–19 digit number is your GUILD_ID — needed once to register the slash commands.
GUILD_ID = 123456789012345678

Discord docs: finding IDs →

4

Create a GitHub Personal Access Token

  • Go to GitHub → Settings → Developer settings → Personal access tokens.
  • Click Tokens (classic) → Generate new token (classic).
  • Give it a name (e.g. discord-issue-bot), set expiry (e.g. 90 days), and select scope repo (full control of private repos — needed so the bot can open issues in your repo, and for PR #181's workflow to pick up ability proposals).
  • Click Generate token and copy it immediately — it's only shown once.
GITHUB_TOKEN = ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
⚠️ Treat this like a password. It can push to your repos. Never commit it to git or paste it in Discord chat — the bot reads it from GITHUB_TOKEN in the environment instead.

Generate GitHub token →

5

Find the role name & wire everything up

  • In Discord: Server Settings → Roles. Create a role named super turbo (or whatever you like) and assign it to whoever may post issues.
  • Copy .env.example → .env in discord-issue-bot/ and fill it in:
VariableWhere you got it
DISCORD_TOKENStep 1 — Developer Portal → Bot

GITHUB_TOKENStep 4 — GitHub PAT
GITHUB_REPO4-mat/bd-autohost-bot-new

  • Register slash commands once: bun src/register.ts
  • Start the bot: bun src/index.ts (or let Render run it — the worker service in render.yaml reads these same env vars from the Render dashboard).
📌 On Render: add these as environment variables on the worker service — they're stored encrypted, never in the repo. Render also supports a Blueprints spec if you want them provisioned automatically.
