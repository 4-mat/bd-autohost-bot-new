Battle Dome Tools

Editors and tools for the bd-autohost-bot-new project

  • Map Editor

    View and edit Battle Dome maps — the curated database plus volunteer maps from maps/*.txt. Save downloads a volunteer .txt you can drop into the repo.

  • Map Gallery

    Browse every map as a thumbnail wall — searchable by name and filterable by game mode.

  • Game Mode Pools

    See which maps are recommended for each game mode — FFA, NTR, Juggernaut, PvP and 1v1.
