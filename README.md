## Local Test Client

A built-in testing environment lets you test commands and HTML pages without connecting the bot to Pokémon Showdown.

Start it with:

```bash
npm test
```

Then open:

```text
http://localhost:3000
```

### Features

- Pokémon Showdown–style chat panel
- Live GUI preview
- Supports bot commands
- No network connection to PS required

### Example Commands

```text
%host

%addp Alice

%addp Bob

%start
```
