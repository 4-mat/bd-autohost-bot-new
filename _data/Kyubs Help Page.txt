===========GENERAL COMMANDS============

%mail [user], [message]
Sends a message to the specified user that they can read when online. A mailbox has a maximum size of 10.
%checkmail
Checks your inbox.
%readmail
Shows the first message in your inbox.
%rename [old name], [new name]
Renames a user. Staff only.
%regp [player], [class], [weapon]
Registers a player. Voice and up only.
%timer [X]
Starts a timer counting down X seconds. Replace X with the desired number.
%stop
Stop a started timer.
%modchat [+/ac/off]
Turn on (or off) modchat with the specified settings. Staff only.
%host [user]
Gives the specified user hosting powers. Voices and up only. Approved hosts can use this command on themselves.
%eventhost [user]
Gives the specified user hosting powers for a 1v1 elobattle; can be shortened to %elohost instead. Voices and up only. Approved hosts can use this command on themselves.
%dehost [user]
Removes hosting powers from the specified user. Hosts may dehost themselves using this. Only voices and up may dehost other hosts.
%dehost elo [user]
Like dehost, except it indicates that the game was an elo game.
%resetwin [winner], [loser]
Resets an elo game’s results. Staff only; can be shortened to %rwin instead.
%relo
Used while playing an elo game to randomize the combos of both players.
%roll [XdY+Z]
Roll a random set of dice. X is the number of dice, Y the amount of sides and Z the added modifier. Approved hosts, hosts and voices and up only.
%reghelp
PMs the user a list of available classes and weapons to choose from for the purposes of registration.
%quote
Brings up a random quote from the bot database. Joke command.
%joke
Brings up a random joke from the bot database. Joke command.
%seal
Brings up a random fact about seals. Joke command.
%praise (input)
Ice Kyubs praises whatever is input after the command. Joke command.
%lynch
Lynches a user. Joke command.
%pick [option1], [option2], ...
Randomly select an option.

===========REFERENCE COMMANDS============
%rf [input]
Brings up a link for the input. Example: %rf changelog brings up the link to the changelog. Useful reference commands: rules, changelog, home, items, glossary
%wt [input]
Gives you data for the input. For example, %wt cursed slice brings up the data for the Cursed Slice attack, %wt longbow brings up all moves Longbows have access to, and %wt burn brings up data for the burn status.
%stats
Returns a table with the stats for all weapons and classes at all levels.
%addmove [name], [class and level], [frequency], [miss rate], [roll], [damage type/action type], [number of targets (Range for AoE)/target group (Foe, Ally or Any)/range], [description]
Adds/Edits a move to Kyubs’ database. Staff only. <- this is buggy and sometimes refuses to work. When using this command, make sure that the arguments are properly aligned before sending the command :)
%addlink [name], [link]
Adds/Edits a link to Kyubs’ database. Staff only.
%addtext [name], [text]
Adds/Edits a text command to Kyubs’ database. Staff only. 

===========BATTLE COMMANDS============

%join [squad number]
Allows you to join a battle if the squad has been opened.
%open
Opens signups for your squad, thus allowing people to use %join to join your battle - you can still use %addp to addp players. Hosts only.
%openbsu
Same as open, but automatically highlights the room after the game is opened.
%close
Closes signups for your squad, thus stopping people from using %join to join your battle - you can still use %addp to addp players. Hosts only.
%autoclose [value]
Will autoclose the game after the amount of time, in seconds, entered in the command. Hosts only.
%setgame [gamemode]
Sets up the game for the desired gamemode. A list of playable gamemodes will be provided after the game is closed. Hosts only.
%pos [pl]+[mode]
Gives you a list of starting positions for the selected game mode and PL size. [pl]+[mode] is formatted as 8pffa, 2v2, etc etc
%hp [value], [user1], [user2], …
Reduce or add the value to all specified users’ HP. Example: %hp -10, Taistelu, MMM would reduce Taistelu and MMM’s HP by 10. If you are a player, you may use %hp value to deduct from or add to your own HP.
%modifystats [player], [stat], [value]
Modifies the stats of a specific player by a certain amount. Value is additive and can be negative; can be shortened to %ms.
%hpm [value], [mob1], [mob2], …
Same as above, except for PVE mobs. Specifying the mob is not necessary if there is only 1 mob in the game. An acceptable alias as a replacement monster name is the corresponding M1, M2, etc. 
%wtm [mob input]
Like %wt, except exclusive to mobs.
%addp [user1], [user2], ...
Add all players specified to the game.
%addm game mode/monster
If a game mode is specified, this will generate a random PvE (FFA) encounter along with all monsters and starting positions for all monsters and players added to the battle. If a monster is specified, all this command will do is add the specified monster. <- Do not use this command. Using %setgame pve is better
%remp [user]
Remove a player from the game.
%remm [monster]
Remove a monster from the game.
%move [letter], [number], (player)
Moves a player to the specified spot on the map. If you are a player you can omit the last argument to move yourself.
%movem [letter], [number], mob
Moves a mob to the specified spot on the map.
%pl (squad)
Brings up the playerlist. Specify the squad name if you’re not a host. (This command works in PMs)
%spectate (squad)
Allows the user to view a live display of the game. Voices and up and hosts only. Hosts do not need to enter the squad number.
%notes add, [note1], (note2), (note3)...
Allows the host to add notes for viewing within the live display.
%notes remove [notenumber1], (notenumber2), (notenumber3)...
Allows the host to remove notes added by %notes add.
%cut [player number]
Highlights and sets a timer for the player with the corresponding player number. Hosts only.
%cutt [value]
Sets the amount of time, in seconds, for the %cut timer to default to.
%checkrange [player1], [player2]
Checks to see if an attack complies with the range rule (noted in %wt rangerule); can be shortened to %cr.
%setlevel [player], [class level], [weapon level]
Sets a player’s class and weapon levels to the ones indicated. Used to balance out PvP games.
%nd
Randomly selects a Natural Disaster from the list of NDs. Used for games where the ND mod is turned on.
%map (squad)
Displays the map for your squad. Omit the squad if you’re the host. This may only be used by hosts or staff in chat, but you can use it in PMs.
%setto
Lets you adjust the turn order in your squad if necessary. (you don’t have to format the input in any particular way.)
%fillsquad
Fills the squad with bots. Staff only.
%ntr
Used to note when one round of NTR has passed, for autoloot purposes.
%to (squad)
Brings up the turn order. Specify the squad name if you’re not a host. (This command works in PMs)
%info (squad) or %status (squad)
Displays the map, pl and turn order of a certain squad in one command.
%sub [player], [sub]
Sub a player. The sub’s HP and position are automatically adjusted if you use this command.
%bp [to], (from)
Passes hosting powers to the target. If you’re a host, you may omit the second argument. (Using this command will probably count as a host leave). 
%addkill [player]
Registers a kill for a certain player.
%remkill [player]
Removes a kill from a certain player.
%kills (squad)
Retrieves the list of kills in order. Specify the squad name if you’re not a host.
%settile [type], [letter], [number], (letter, number, …)
Sets the tiles chosen to be of the given type. Needs at least one tile to be given, but can set many at a time. Tile type can be written at the start or end of the command. Note that %tile is an alias of %settile. Hosts only.
%gchat (repost)
Creates a gchat with the squad name - use this if you host a 1v1 or a second match. Using the argument repost will post the groupchat link in the room.
%hosts
Returns the list of hosts. Roomauth only.
%bsu (sub)
Highlight the entire room with a hopefully generic boring Kyubs quote. Using the argument sub will ask for a sub.
%juggernaut
Chooses the highest level player to be the juggernaut for a Juggernaut game. Randomizes if the highest level is tied.
%genpos [PL Amount][Game Mode]
This automatically sets positions for all gamemodes excluding Team Modes and PvE. 
Example: %genpos 4pffa
%il or %itemlist (squad)
Shows the equipped items used by the players in that squad. Can omit squad number if you’re the host.

===========CHARACTER COMMANDS============

%vl (user)
Displays the user’s EXP and Class/Branch levels. The user part can be ignored if you are checking your own levels.
%vs (user)
Displays the user’s EXP, stats and current class/weapon. The user part can be ignored if you are checking your own stats.
%vsplus (user)
Same as %vs, but more detailed and shows total XP.
%level class | %level weapon
Level either your current class or your current weapon by 1 level, respectively, if you have the required EXP. (Do not replace class/weapon with the class or weapon name!) Use %rf xpchart if you want to see if you have the required EXP.
%sco [class], [weapon]
Switches your current class and weapon combination to the one specified.
%save [number]
Saves your current combo to a “saveslot” to be loaded later. 
%saved 
Displays all your saved combos.
%load [number]
Loads the combo selected, replacing your current combo.
%regp [user], [class], [weapon]
Registers a user into Kyubs’ player database with the specified class and weapon. Voices and up only.
%elo (user)
Check either your own elo, by omitting the user, or somebody else’s elo, which is used for competitive 1v1 battles.
%elorank
Check the placings of everyone in the elo rankings.
%viewitems/%vi
Displays your character’s Gold, Gems and Items.
%loot confirm
Confirms the autoloot of a game that has ended recently. Voice and up only.
%loot delete
Deletes the autoloot of a game that has ended recently. Voice and up only.
%loot [value], [user]
Gives the EXP and Gold value to the specified user(s). Multiple users can be used, for example: %loot 5, Taistelu, MMM, Microwavable would give 5 EXP and Gold to all three users. Voices and up only. Value cannot exceed 20. Generally used as a backup command.
%buyitem [item]
Shows the data of the Item and gives you the option to %buyitem confirm.
%buyitem confirm
Confirms the purchase of an item.
%equip [item]
Equips an item you currently own.
%unequip [item]
Unequips an item you currently have equipped. Replace [item] with all to unequip all items.



===========BACKUP/LEGACY COMMANDS============
Commands that are here are either made irrelevant by other commands or simply have no use anymore - generally don’t wanna use the hosting ones.

%gento
Automatically generates a turn order for your squad.
%setmap [game mode]
Set the map for your squad. Valid arguments are 1v1, pvp, pvpvp, jugg, etc. Auth can use %setmap [map name].
%sc [class]
Switches the user to the specified class.
%sb [branch]
Switches the user to the specified weapon branch. This command is literally pointless, have fun.
%sw [weapon]
Switches the user to the specified weapon, only if the user is in that weapon branch.
%xppay [user], [amount]
It removes XP from the player’s bank (seen in %vsplus) to spend on rewards in the 4.2 Prize Shop which no longer exists. Staff only.
%givegems [Amount], player1, player2, player3,...
Gives players a certain amount of gems. 3p-4p is 1 Gem, 5p-6p is 2 Gems, and 7-8p is 3 Gems. Voices and up only. 
%xp [value], [user]
Gives the EXP value to the specified user(s). Multiple users can be used, for example: %xp 5, Taistelu, MMM, Microwavable would give 5 EXP to all three users. Voices and up only. Value cannot exceed 20.
%win [winner], [loser]
Registers an elo game result. Voices and up only.
